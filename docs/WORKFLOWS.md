# Workflows

## Starting a Task

1. Read `graph/project_graph.md`.
2. Read `graph/codex_task_map.md`.
3. Read `docs/HANDOFF.md`.
4. Choose one scoped task.
5. Confirm the task does not require copied brands, logos, or protected assets.

## Completing a Task

1. Make the smallest useful change.
2. Keep scope focused on the companion app.
3. Update `docs/HANDOFF.md` with work completed, files changed, and next step.
4. Stop and report clearly.

## MVP Planning Flow

1. Define dashboard data needs.
2. Map roster, depth chart, weekly prep, and tracking pages.
3. Add AI report and recap structures.
4. Add Video Board and Info Board content models.
5. Review branding compliance before visual work.
