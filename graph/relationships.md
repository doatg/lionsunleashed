# Relationships

- Rolland G uses the companion app to manage Franchise mode externally.
- Dashboard summarizes Team Profile, Roster / Depth Chart, Weekly Game Prep, Weekly AI Report, Injury / Transaction Tracker, Contract / Cap Notes, Scouting / Draft Board, Broadcast Recap, Video Board, and Info Board signals.
- Team Profile anchors Franchise context, team direction, roster philosophy, and screen-level planning.
- Roster / Depth Chart informs GM Advisor, Contract, Injury Tracker, Transaction, Weekly Opponent Prep, and Weekly AI Report decisions.
- Weekly Game Prep connects roster status, injuries, depth chart needs, opponent focus, and postgame recap context.
- Weekly AI Report synthesizes prep, roster, injury, transaction, contract, and scouting signals into recommendations.
- Injury / Transaction Tracker keeps player availability and roster movement connected to depth chart and weekly planning.
- Contract / Cap Notes supports roster decisions, transaction planning, and scouting priorities.
- Scouting / Draft Board supports long-term roster construction through DraftProspect notes and needs alignment.
- Broadcast Recap turns game outcomes into franchise storylines and can feed Video Board and Info Board items.
- Video Board organizes media notes connected to players, weekly prep, and recaps.
- Info Board presents quick-reference franchise facts connected to the franchise, team, players, and recaps.
- Handoff records completed work and next steps after each task.
- Brand Safety constrains all naming, visuals, assets, and copy.
- Phase 4 App Scaffold Planning maps the first implementation task to a Vite React TypeScript scaffold with npm as the default package manager.
- The first app structure connects `src/main.tsx`, `src/App.tsx`, `src/styles.css`, `src/data/mockFranchise.ts`, `src/types/franchise.ts`, `src/components/`, and `src/screens/` to the Dashboard-first vertical slice.
- The first vertical slice uses static mock data only and excludes API/backend work, real Madden file parsing, external media ingestion, and protected or licensed visual material.
